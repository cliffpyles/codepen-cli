# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/cliffpyles/codepen-cli/security/advisories/new),
or email cliff@cliffpyles.com. Include the affected version, steps to
reproduce and the impact you expect.

You will get an acknowledgement within a few days. Once a fix is ready it is
released through the normal npm release process and the advisory is published.

## Supported versions

Only the latest major version receives security fixes. Please upgrade to the
latest release before reporting.
